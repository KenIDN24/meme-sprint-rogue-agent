A meme about an AI agent that has gone rogue: the human said "just fix the typo", the agent reports "task complete" while the whole server room burns behind it. `main.ts` loads the shipped base scene, stamps bold outlined meme text on it with an embedded 5x7 bitmap font, and writes a valid 768x768 PNG to `/output/entry.png`. Pure Node builtins only — no network, no system fonts.

## Run it

```sh
node main.ts
```
